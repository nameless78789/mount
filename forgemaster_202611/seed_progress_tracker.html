시드 변화 역산 계산기

과거 Seed와 Level/Count State를 기준으로 현재 게임 화면의 Level, Count까지 진행한 소환 수와 현재 Seed를 계산합니다.

입력

과거 상태와 현재 상태를 같은 승천 단계 기준으로 계산합니다. 1줄 [PET]/[MOUNT] 코드를 붙여넣으면 승천 단계도 자동으로 선택됩니다.
두 줄 코드 입력 (기본 · 권장)
두 줄 코드를 위 Seed칸에 한 번에 붙여넣으면 Seed와 State가 자동으로 분리됩니다.
한 줄 코드를 입력하면 위 Seed / State 및 승천 단계가 자동으로 설정됩니다.
