알 소환 비교 테이블

기본 소환과 보너스 소환을 함께 비교하는 테이블입니다. 같은 Seed에서 기본 소환 등급과 보너스 소환 등급을 한 줄에 함께 표시합니다. 패치 후 기준으로 스탯은 기본/보너스 소환일 때 동일하며, RNG1 기준으로 계산한 펫 이름도 함께 표시합니다.

※ 최신 EggSummonConfig.json을 HTML과 같은 폴더에 두고 실행하세요. 기존 Seed / State 두 줄 형식으로 입력하세요. 최근 [PET] 32자리 코드는 아래 변환 기능을 이용할 수 있습니다. 0~2승천은 Lv.100까지, 3승천은 Lv.150까지 지원합니다.

최근 [PET] 한 줄 코드 → 기존 Seed / State 변환
⚠ 최근 Lua는 Level / Count를 각각 1바이트(0~255)만 출력합니다. Lv.126 이상은 카운트가 255를 초과할 수 있어 변환을 지원하지 않습니다. Lv.125 이하에서도 변환된 레벨과 카운트가 실제 게임 화면에 표시되는 값과 정확히 일치하는지 확인한 후 시뮬레이션을 실행하세요. 일치하지 않으면 변환 결과를 사용하지 마세요.
Level/Count는 현재 소환 단계를 표시합니다. 예를 들어, 3/20 상태에서 소환할 경우 이번에 나오는 결과는 4/20번째 알입니다.
스탯 개수는 승천 기준으로 표시하여, 항상 2개로 처리합니다. 최대 비교 개수는 2000개까지 지원합니다.
