탈것 소환 비교 테이블

Seed값에 대한 기본 소환 테이블과 보너스 소환 테이블을 비교해서 함께 표시합니다. 탈것은 기본 소환일 때와 보너스 소환일 때 스탯이 다릅니다.
※ 기존 Seed / State 두 줄 형식으로 입력합니다. 최근 [MOUNT] 한 줄 코드는 아래 변환 기능을 이용하세요.
최신 MountSummonConfig.json 파일을 HTML과 같은 폴더에 두세요.
최근 [MOUNT] 한 줄 코드 → 기존 Seed / State 변환
⚠ 최근 Lua는 Level / Count를 각각 1바이트(0~255)만 출력합니다. Lv.126 이상은 카운트가 255를 초과할 수 있어 변환을 지원하지 않습니다. 그 이하에서도 변환된 레벨과 카운트가 실제 게임과 일치하는지 확인하세요.
Level/Count는 현재 소환 단계를 표시합니다. 예를 들어, 3/20 상태에서 소환할 경우 이번에 나오는 결과는 4/20번째 탈것입니다.
승천 상태에서는 등급과 관계없이 모든 탈것의 스탯을 2개로 계산하며, 최대 비교 개수는 2000개까지 지원합니다.
상세 필터 등급 · 옵션 · 완성도
옵션 (복수 선택)

AND: 선택한 옵션 중 2개가 같은 펫 또는 탈것에 함께 있는 경우. 옵션 하나만 선택하면 AND와 OR는 같습니다.
