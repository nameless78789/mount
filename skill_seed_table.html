스킬 소환 테이블

현재 Skill Seed와 Level/Count 기준으로, 보유 재화로 소환 가능한 스킬 결과를 순서대로 표시합니다.
※ 12줄 HEX코드 중 4번째 줄이 스킬 시드(Seed), 5번째 줄이 스킬 레벨카운트(State) 값입니다. 2줄로 복사된 Seed와 State를 Seed칸에 붙여넣으면 자동으로 분리 입력됩니다.
Level/Count는 현재 소환 단계를 표시합니다. 예를 들어, Count 3/20 상태에서 소환할 경우 이번 결과는 Count 4/20번째 스킬입니다.
사용 재화와 5회당 소환 비용을 입력하면, 소환 가능한 횟수만큼 결과를 자동으로 표시합니다. 최대 10,000회까지 지원합니다.
